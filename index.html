Easy to run

One command starts it. Your feeds and stories are kept in one database, and one more command backs it up, even while it runs.

Everything for reading

Folders, unread counts, Saved for Later, search, and several ways to lay out your stories.

Quick and quiet

No AI and nothing extra running in the background. Stories open the moment you click them.

What’s inside

Five layouts

Full, Split, List, Magazine and Grid. Each feed remembers its own.

Four views

Read the feed, the full article text, the original site or the story page.

Drag & drop

Arrange feeds and folders however you like.

One-click mark as read

Click an unread count and the feed is done.

Saved for Later

Keep stories you want to come back to, with tags.

Search

Find any story you have received.

Keyboard shortcuts

Read without the mouse. Press ? to see them all.

Easy to move in

Import your feeds from another reader, or your whole NewsBlurMod account.

What you won’t be installing

NewsSharp is two small Python processes and one database file. Nothing else runs beside it, so it uses little memory and fits on a cheap VPS, a home server or an old laptop.

Docker

You need Python and Git. The installer sets up everything else.

Redis

No cache or message queue to run. The database passes the work along.

MongoDB

Feeds and stories are kept in ordinary database tables.

PostgreSQL

Everything is in one SQLite file. Copy it and you have a backup.

  • Also not needed:
  • Celery→ its own process pool
  • Elasticsearch→ search built into SQLite
  • Node.js→ the interface comes prebuilt
  • Kubernetes→ one command starts it
  • nginx→ optional, for HTTPS

Pairs with Feedxcavator

Not every site has a feed. Feedxcavator, a companion project, makes feeds out of web pages, and NewsSharp is built to read them.

Feeds from any page

Point it at a page, say which parts are the stories, and you get a feed to subscribe to.

Stories arrive at once

Feedxcavator sends new stories to NewsSharp as soon as it finds them, without waiting for the next check.

A button away

Give NewsSharp its address and two buttons appear in the sidebar: one opens Feedxcavator, the other asks it for fresh news.

Install

You need Python 3.12 or later. Then:

git clone https://github.com/GChristensen/NewsSharp
cd NewsSharp
python3 install.py
./newssharp.sh

On Windows, run python install.py and newssharp.cmd. Then open the address the installer shows and create your account. To run it on a server, see the README.
